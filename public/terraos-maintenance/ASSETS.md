# TerraOS 3 maintenance visual assets

## Shipped originals

The following SVG environments are original Solaris Studio artwork committed with this repository. They are intentionally local so the maintenance surface does not depend on third-party image hosts.

- `blue-motion.svg` — immersive blue motion chapter.
- `live-stage.svg` — contest-night / Live chapter.
- `purple-tunnel.svg` — gallery/finale transition texture.

## Licensed-photo candidates

The composition is deliberately built so a licensed photograph can later replace or layer over an SVG environment without changing layout or interaction code.

Candidates selected during design review:

- Blue motion/dance: Jimmy Liu, Unsplash, `https://unsplash.com/photos/silhouettes-of-dancers-on-a-blue-illuminated-stage-hht3DaReyS4`
- Live stage: Jack Dong, Unsplash, `https://unsplash.com/photos/concert-stage-with-bright-lights-and-audience-silhouette-E7cSIwvOQ0s`
- Purple abstract environment: Logan Voss, Unsplash, `https://unsplash.com/photos/abstract-tunnel-of-purple-and-pink-light-p-tsgC5Ur3s`

These external images are **not currently shipped or hotlinked**. Before any binary is added, verify the individual source page and then store the approved optimized asset locally. Do not infer endorsement or Solaris participation from recognizable people in third-party photography.
